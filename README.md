# BoneSim 骨透かしシミュレーター

骨格モデルを **実際の関節中心・関節軸のまわりに** 動かし、骨同士がどう動くか（橈骨が尺骨のまわりを回る、肩甲上腕リズム、膝のスクリューホームなど）を観察するための教育用アプリです。Webカメラの映像から姿勢を推定して、X線風の骨を重ねて表示することもできます。

> **教育用の推定モデルです。実際の骨や画像ではなく、診断・撮影の判断には使用できません。**

## 起動方法

ブラウザの制限により、`index.html` をダブルクリックで直接開くと動きません。付属のスクリプトで簡易サーバー（`serve.py`、Python 3 標準ライブラリのみ）を起動してください。

| OS | 手順 |
|---|---|
| Windows | `start.bat` をダブルクリック → サーバーが起動してから既定のブラウザで `http://localhost:8000/` が開きます。`py`（Python ランチャー）→ `python` の順に探します。Python が無い場合は https://www.python.org/downloads/ からインストール（「Add python.exe to PATH」にチェック）。 |
| macOS / Linux | ターミナルで `./start.sh` |
| 手動 | このフォルダで `python serve.py`（または `py -3 serve.py`） |

- ポート 8000 が使用中なら 8001, 8002… を自動で使います（表示されるURLを開いてください）。
- `serve.py` は `.js` `.wasm` `.glb` などのMIMEタイプを正しく返すので、Windows のレジストリ設定に左右されません。
- 終了するときはサーバーのウィンドウを閉じます（または Ctrl+C）。インターネット接続は不要です（three.js・MediaPipe・モデルは同梱）。

## 使い方

### シミュレーターモード
- **プリセット動作**：「肘の屈曲・伸展」「前腕の回内・回外」「肩の外転（肩甲上腕リズム）」「肩の屈曲」「膝の屈伸（スクリューホーム）」「手関節の掌屈・背屈」「体幹の回旋」「グー・パー」。再生／一時停止と速さを変えられます。再生中は画面下に解剖学的な解説（その瞬間の角度つき）が出ます。
- **連動運動 ON/OFF**：OFFにすると「骨を1つずつ単純に回す」モデルになります（前腕は棒ごとねじれる、肩甲骨は動かない、膝は単純な蝶番、など）。ONと見比べると、実際の関節運動の特徴がわかります。
- **関節を動かす**：体幹・頸部／右上肢／左上肢／右下肢／左下肢／手指のスライダー（日本整形外科学会・日本リハビリテーション医学会の関節可動域の範囲内）。「解剖学的正位」（手掌が前）と「中間位」（前腕回内外0°）にリセットできます。
- **表示**：X線風／骨／半透明皮膚つき、白黒反転（フィルム風）、関節軸、骨指標（ランドマーク）、視点（正面・側面・後面・上肢アップ・膝アップ）。マウスのドラッグ／指で回転・ズームできます。
- **骨をタップ／クリック**すると、骨の名前と「その骨を動かす関節」が表示されます。

### カメラモード
1. 「カメラ」タブ → 入力「Webカメラ」→「▶ 開始」。初回はカメラの許可を求められます。
2. 全身（または上半身）が映る位置に立ちます。
3. 「キャリブレーション」：カメラに正対し、腕を体から少し離して2〜3秒静止すると、骨の長さが体格に合わせて調整されます（ブラウザに保存）。
4. オプション：鏡像表示、前面／背面カメラ切替、3Dビューを並べて表示、映像を暗くする、手の追跡（重い場合はOFF）、モデル（スマホは「軽量」推奨）、信頼度が低い骨を薄く表示。
- カメラが無くても、入力を **「デモ（合成データ）」** にすると、合成した関節位置から同じ処理を通して動作を確認できます。
- 推定の限界：前腕の回内外・手関節は手がはっきり映っているときのみ比較的正確です。肘を伸ばしていると肩の回旋と前腕の回内外は区別できません。肩甲骨・鎖骨・膝蓋骨・スクリューホーム・脊柱の分配は、映像からではなくモデルで推定しています。

## スマートフォンで試すには
- スマホのブラウザでカメラを使うには **HTTPS**（または同じ端末の `localhost`）が必要です。PC で `python serve.py --lan`（Windows は `start.bat --lan`）とすると、表示される `http://192.168.x.x:8000/` を同じWi-Fiのスマホで開けます。ただし **シミュレーターモードは動きますが、カメラは使えません**（HTTPSでないため）。
- まずは PC（`localhost`）で試すのが簡単です。
- スマホでカメラモードを使う方法の例：
  - HTTPS で配信する（GitHub Pages / Netlify などの静的ホスティングにこのフォルダをそのまま置く。将来的な公開方法の候補）。
  - 開発用に HTTPS の簡易サーバーやトンネル（例：`npx http-server -S`、Cloudflare Tunnel など）を使う。
- スマホではモデル「軽量」・手の追跡OFFにすると軽くなります。

## 連動運動のモデル（概要）
| 部位 | モデル |
|---|---|
| 肩 | Pose は上腕骨と胸郭の角度。最初の約30°は肩甲骨はほぼ動かず、その後は挙上1°あたり0.4°の上方回旋（180°で60°、全体で肩甲上腕関節2：肩甲骨1、Inman）。後傾は最大約20°、外旋は最大約10°。鎖骨は挙上とともにわずかに挙上（最大約6°）・後退（最大約18°）し、90°以降は長軸まわりに後方回旋（最大約35°）（Ludewig 2009 の傾向。Inman の古典値も選択可）。伸展方向では上方回旋せず軽く前傾。肩甲骨が胸郭にめり込まないよう、肩甲骨の内旋・傾きを自動で最小限補正。肩甲上腕関節の回転は「肩甲骨の向き⁻¹ × 目標の上腕骨の向き」なので、上腕骨の向きは Pose どおり。 |
| 肘・前腕 | 運搬角：伸展位で上腕骨幹と尺骨幹のなす角 約10°（外反）。屈伸軸は内側端がやや遠位に傾いた斜めの軸で、屈曲するにつれ前腕は上腕骨の上に重なる（90°でほぼ矢状面）。骨モデルの元の姿勢はやや内反なので、リグで補正しています。橈骨は尺骨の子で、橈骨頭中心→尺骨頭中心の軸まわりに回内外。手根骨・手は橈骨の子。 |
| 手関節 | 掌屈は 橈骨手根関節：手根中央関節 ≈ 4：6、背屈は ≈ 2：1（66.5：33.5）、橈屈・尺屈は 6：4（Sarrafian 1977）。 |
| 手指 | MP・PIP・DIP（DIP 未指定時は PIP の 2/3）、母指 CM・MP・IP。 |
| 膝 | 大腿骨に対し脛骨が屈曲軸まわりに回転。伸展の最後の約20°で最大10°外旋（スクリューホーム）。膝蓋骨は膝の屈曲角の約0.7倍だけ傾きながら滑車溝を滑り、大腿骨に食い込まないよう接触を保つ。 |
| 足 | 距骨は距腿関節軸（内果・外果を結ぶ軸）、踵骨以下は距骨下関節軸（Inman の平均軸）まわり。 |
| 脊柱 | 屈曲は腰椎約70%・胸椎約30%、側屈は胸椎約50%、回旋は胸椎約75%（White & Panjabi）。頸部の回旋は約50%を環軸関節が担う。合計は Pose と一致するよう補正。 |

注：BodyParts3D の膝蓋骨は低い位置（大腿四頭筋が弛緩した状態）にあり、安静時の膝蓋腱長（約25 mm）はたるんでいるとみなし、張った長さ（約28〜29 mm）に達してからは長さ一定としています。

## 既知の制限
- **実際の人物でのカメラ追跡精度は未検証**です（テストは合成データのみ）。表示はあくまで推定です。
- 真横（側面）や、カメラに向かって伸ばした腕・脚は、奥行きの推定誤差が大きく精度が落ちます。
- 前腕の回内・回外と手関節は、手がはっきり映っている（手の追跡ON）ときのみ比較的正確です。肘を伸ばしていると肩の回旋と前腕の回内外は区別できません。
- 肩甲骨・鎖骨・膝蓋骨・スクリューホーム・脊柱の分配は映像からではなくモデルによる推定です。骨は標準的な骨格（BodyParts3D）を体格に合わせて伸縮したもので、本人の骨ではありません。
- 皮膚表示は簡易スキニングで、大きく動かすと一部に隙間ができます。尾骨は含まれていません。
- 対応ブラウザ：最近の Chrome / Edge / Safari（**Safari 16.4 未満は非対応**：MediaPipe の SIMD 版のみ同梱）。スマホは機種によって動作が重くなります（モデル「軽量」・手の追跡OFF推奨）。
